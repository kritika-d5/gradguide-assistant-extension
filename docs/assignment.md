# Assignment brief: Course Recommendation Assistant (GradGuide)

## Background

GradGuide runs counselling sessions for students planning to study abroad. Counsellors weigh a
student's academic background, career goals, budget, preferred country, intake and other factors.
The key problem is **consistency**: similar students can get different recommendations depending
on the counsellor. The tool should make recommendations more structured and consistent
**without replacing the counsellor's judgment**.

## Build

A Course Recommendation Assistant used during a live counselling session that takes the student's
profile and the counsellor's input and surfaces relevant courses, universities and course info:

* Recommend relevant courses based on the student's profile
* Show university, country, fees, intake and eligibility
* Explain why a course may be relevant
* Let the counsellor explore alternative recommendations
* Let the counsellor search or ask questions about courses

## Live counselling experience

The session may already be on Google Meet. The assistant must work alongside the meeting without
disrupting it. The interaction model is the candidate's choice (extension, floating panel, side
panel, sticky note, or other).

## Product decisions left to the candidate

How the profile is captured, how courses are matched and ranked, how recommendations are
explained, how incomplete information is handled, and how course data is structured and updated.

## Three original features

No suggested list. For each: the problem it solves, why it matters, how it works.

## Deliverables

* Working application (hosted link or clear run instructions)
* Source code (GitHub repository)
* Short write up: recommendation approach, interface, three feature decisions
* Short video walkthrough added to the GitHub README

## Evaluation

* Quality and relevance of recommendations
* Understanding of the counselling problem
* Live meeting experience and usability
* Consistency and explainability of recommendations
* Quality of the three original features
* Code quality and ability to explain design decisions
